# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi and single-package repositories.

Each changeset describes a set of changes that need to ship together. To create one, run:

```
npm run add-changeset
```

When making a follow-up change to an unreleased feature, **extend the existing changeset md file** rather than adding a new one.

See the [common questions](https://github.com/changesets/changesets/blob/main/docs/common-questions.md) for more.
